# 🌊 Bluewave Water Park Management System

A comprehensive web-based management and ticketing system built for Bluewave Water Park to manage online ticket bookings, rides, packages, visitor management, and administrative operations.

---

## ✨ Features

- 🎟️ **Online Ticket & Package Booking:** Visitors can select dates, packages, ticket counts, and view dynamic pricing.
- 💳 **Checkout Flow:** Order summary, automated price/tax calculation, and digital booking confirmations.
- 🏄 **Attractions & Rides Showcase:** Display water park attractions, timing, safety rules, and height restrictions.
- 🔐 **Authentication & Security:** User registration, login, and secured admin access.
- 📊 **Admin Dashboard:** Manage bookings, view visitor statistics, update ticket pricing, and track revenue.
- 📱 **Responsive Design:** Optimized layout for desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

- **Frontend:** React.js / HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js (or PHP)
- **Database:** MySQL
- **Environment:** XAMPP / Visual Studio Code

---

## ⚙️ Local Setup Instructions

### 1. Database Setup
1. Start **Apache** and **MySQL** in XAMPP.
2. Open phpMyAdmin (`http://localhost/phpmyadmin`).
3. Create a database named `bluewave_db` and import the schema file (if available).

### 2. Project Setup
```bash
# Clone the repository
git clone [https://github.com/damsaraninawela2002-ux/bluewave-water-park.git](https://github.com/damsaraninawela2002-ux/bluewave-water-park.git)

# Navigate to project folder
cd bluewave-water-park

# Install dependencies (if using Node.js)
npm install

# Start the application
npm start  # or npm run dev
